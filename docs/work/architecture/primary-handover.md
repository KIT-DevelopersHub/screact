# OS 操作権（主トラック）の受け渡し（方式 A・試作）

Issue #23（親 #4）のメモ。`two-person-two-hand-integration-sheet.md` は変更していない。

## 現状の主トラック方式

- OS のマウスカーソルは 1 つなので、`MultiHandEngine` は主トラックのイベントだけを OS へ流す（`primaryEventsOf`）。ほかのトラックのイベントはオーバーレイにだけ渡す。
- 主トラックが無いとき、画面内に 2 フレーム続けて現れた手のうち、trackId の小さい方を主トラックにする。
- 主トラックは、その手が確定消失するまで変わらない。画面外に出ても、一時欠落の猶予中（`lostTrackIds`）でも持ち続ける（#39 の方針）。

### 課題

主トラックの手が画面内にあるかぎり、もう 1 人は OS を操作できない。操作を代わるには、主トラックの人が手をカメラから外し、猶予（既定 300ms）が切れるのを待つ必要がある。

## 試作した方式

設定「操作権の受け渡し（試作）」を ON にすると、主トラックでない手が一定時間（既定 500ms）ピンチを保ったときに操作権をその手へ移す。既定は OFF で、OFF のときの挙動は従来と同じ。

条件は次のとおり。

| 条件 | 実装 |
| --- | --- |
| 主トラックが押下中・ドラッグ中のときは移さない | 主トラックが押下中のあいだは保持時間を数えず、離した後に改めて 500ms 数える |
| 主トラックが猶予中のときは移さない | 猶予中は保持時間を数えない。#39 の「猶予中は所有権を他へ移さない」を崩さない |
| 旧主トラックの押下を閉じてから移す | 移すフレームは旧主トラックのイベントだけを OS へ流し、新しい主トラックは次のフレームから流す。押下が残っていればクリックなしで閉じる（上の条件により通常は残らない） |
| 移した直後の 1 回目のピンチをクリックとして流さない | 受け渡しに使ったピンチの押下をクリックなしで閉じ、ピンチを離すまで再押下させない。そのあいだはカーソル移動だけを流す |

- 保持時間はフレームの `capturedAtMonotonicMs` で測る。候補は画面内にあり、猶予中でない手だけ。
- 保持の途中でピンチを離したり、候補が猶予に入ったりしたら数え直す。
- ピンチの判定は各トラックのクリック（押下）状態を使う。そのため、ジェスチャー設定でクリックを OFF にしているときは受け渡しも起きない。

## 実装の場所

- `desktop/lib/core/multi_hand_engine.dart`: `primaryHandoverEnabled`・`primaryHandoverHoldMs`・`_advanceHandover`
- `desktop/lib/core/interaction_engine.dart`: `isPressed`・`cancelPress`
- `desktop/lib/ui/home_page.dart`: ハンドジェスチャー設定ダイアログのスイッチ。`primary_handover` ファイルに永続化する
- `desktop/test/primary_handover_test.dart`: 上の条件のテスト
