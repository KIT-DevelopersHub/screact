# Screact 作業用・履歴資料

このディレクトリは、実装済み機能の仕様書ではなく、開発の作業を再開・検証・判断するための資料です。現行の実装を確認したい場合は、親ディレクトリの [Version 1.0.0 仕様書](../README.md#仕様書構成) を先に参照してください。

## 構成

| ディレクトリ | 内容 | 状態 |
| --- | --- | --- |
| [architecture/](./architecture/) | ペアリング、位置合わせ、複数手の補助シーケンス | 実装補助・設計資料 |
| [requirements/](./requirements/) | 要件、カメラ判断、実機デバッグ、変更計画 | 要件・検証資料 |
| [reviews/](./reviews/) | 手座標・ジェスチャー精度のレビュー | 特定時点の評価 |
| [planning/](./planning/) | QR、リレー、iOS を含む接続案 | 将来計画 |
| [records/](./records/) | 開発台帳、作品資料の採用根拠、移行履歴 | 開発記録 |

## 使い方

1. 新しい機能の実装可否は、先に `../` の実装仕様書とコードを確認する。
2. 設計案・PR案・要件文書は、実装済みの機能説明へ転記しない。
3. 仕様書の構造を変える場合は、`records/migration/` に旧パスと新パスの対応を残す。
