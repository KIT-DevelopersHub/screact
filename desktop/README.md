# デスクトップアプリ

Androidアプリから受信した手指の骨格データを利用して、PC上でポインター操作や描画操作を実現するアプリです。

## ディレクトリ構成

デスクトップアプリの技術選定・実装は別途進めます。現時点では、以下の構成を想定しています。

```text
desktop/
├─ README.md       # デスクトップアプリの概要・開発メモ
├─ src/            # アプリケーションのソースコード
├─ tests/          # テストコード
├─ assets/         # アイコンなどのアプリ用素材
└─ ...             # 使用する開発環境に応じた設定ファイル
```

## 想定する役割

- Android端末とのWebSocket接続
- 受信した手指骨格データの解析
- カメラ座標から画面座標への変換
- ポインター、クリック、ドラッグ、スクロール、描画などの操作
- ログ保存とデバッグ表示

## 開発メモ

使用する言語・フレームワーク・ビルド方法は、デスクトップアプリの担当者が決定した後に追記します。
